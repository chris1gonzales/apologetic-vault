# Veritas v3.5 — Logic & Transcendental Argument

Adds a standalone sidebar module with the three classical laws of thought, deductive and nondeductive inference, 24 searchable logical fallacies with examples and responses, a carefully qualified Van Tilian transcendental argument for God (TAG), distinctions between Van Til, Bahnsen, and Bavinck, six locally scored practice exercises, bibliographic leads, and browser-local notes with JSON export.

Preserves all v3.4 modules, including Inerrancy & Textual Criticism. No AI features, remote analytics, or external services are added. External source links open only when selected.

Deploy by extracting files to the repository root, then running `npm ci && npm run build`. Netlify publish directory: `dist`. Notes are local to the browser and are not automatically synced between devices.

Scholarly caution: TAG's necessity/exclusivity premise is contested; the module presents it as an argument requiring defense, not as an undisputed logical theorem.
