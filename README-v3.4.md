# Veritas v3.4 — Inerrancy & Textual Criticism

Adds ten research studies covering Dead Sea Scrolls, Isaiah, Masoretic Text and Septuagint, New Testament manuscripts and major variants, early Christian writers, archaeology, canon, biblical inerrancy, and comparative preservation. Includes searchable navigation, sources, apologetic research method, local notes, and JSON export.

Existing Veritas modules are retained. Deploy ZIP contents at repository root. Build with `npm run build`; publish `dist`. No AI integrations.
