# Veritas Theology & Apologetics v3.0

## New: Christology & Islam

A dedicated, mobile-responsive research module comparing John 1:1–14, John 20:28 and Hebrews 1:8–12 with Qur'an 5:72. It includes original-language observations, contextual interpretation, objections and Reformed Baptist responses, presuppositional analysis, a comparison matrix, source links, and browser-local notes with text export.

### Deploy

Upload the **contents** of this archive (not an enclosing folder) to the root of your GitHub repository. Netlify build command: `npm run build`; publish directory: `dist`. The archive includes `package-lock.json` for reproducible installs.

### Limitations

The source ZIP was checked for integrity. An end-to-end production build could not be performed in this environment because npm dependencies were unavailable in the offline cache. Primary-source links require internet access. Browser-local notes are not synced.
